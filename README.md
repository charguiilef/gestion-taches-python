# Application Python de Gestion des Tâches

## Description
Ce projet est une application console en Python permettant de gérer des tâches quotidiennes. Il a été réalisé en binôme dans le cadre du module *Outils collaboratifs avec Git / GitHub* (Licence 1).

## Fonctionnalités
* **Ajouter une tâche** : Saisie d'un titre non vide et ajout à la liste.
* **Afficher les tâches** : Affichage numéroté de toutes les tâches enregistrées.
* **Rechercher une tâche** : Filtrage des tâches à partir d'un mot-clé.
* **Quitter** : Fermeture propre du programme avec gestion des erreurs de saisie.

## Étapes réalisées
1. Création de la structure de base du menu, de l'ajout et de l'affichage des tâches dans `main.py`.
2. Rédaction de la documentation du projet dans `README.md`.
3. Ajout de la fonctionnalité de recherche par mot-clé dans `main.py`.
4. Synchronisation du projet sur GitHub et ajout d'une mise à jour post-publication.

## Exécution du programme
1. Ouvrir le dossier du projet dans **Visual Studio Code**.
2. Cliquer sur le fichier `main.py` dans l'explorateur à gauche.
3. Cliquer sur le bouton **▶ Run Python File** en haut à droite de l'éditeur.
4. Suivre les instructions affichées dans le terminal intégré en bas de l'écran.
